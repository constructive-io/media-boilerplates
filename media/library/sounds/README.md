# sounds

The files the banks in [`banks/`](../banks) play. A bank names a file by its
path from this folder: `file: rain.flac`, or `file: weather/rain.flac`.

Put only sounds here that you made, or that came with a license that lets you
pass them on. Say which in the library's README.

A short video can be one of them: a bank names it like any sound, and a script
cuts to it with `[video NAME]`, playing its sound as it does. An opening title
is the usual one. Keep it to seconds: a repository is no place for footage.
